# 免译隐私政策

生效日期：2026 年 10 月 4 日

免译是一款在浏览器中提供网页、划词与视频字幕翻译，以及本机词本功能的扩展。使用免译不需要创建账户。

## 处理的数据

- 为翻译和字幕功能，扩展会读取用户正在使用的网页中与该功能有关的文字、选区、字幕，以及必要的页面或视频地址。
- 扩展会处理用户的划词、点击翻译及收藏操作，以显示对应结果或保存用户选择的内容；不会建立通用的点击或按键历史。
- 用户主动保存的生词、句子、词本、视频收藏、设置与翻译结果会保存在 Chrome 扩展本机存储中。
- 用户自行填写的第三方服务 API Key 会保存在 Chrome 扩展本机存储中，并在调用相应服务时直接发送给该服务进行身份验证。

## 数据发送对象

用户触发翻译功能时，完成该次请求所需的文字和语言设置可能直接发送至 Google 翻译。用户选择并配置其他翻译或 AI 服务时，相关文字、字幕、提示内容及所需 API Key 会直接发送至其选用的服务商，例如 OpenAI、Google Gemini、DeepL、Anthropic 或 DeepSeek。视频字幕功能也可能向用户正在浏览的视频网站请求字幕。各服务商对其收到的数据适用其各自的隐私政策。

免译不运营账户或翻译代理服务器，不向原产品的托管服务发送内容，也不向分析平台发送使用行为或安装遥测。扩展不出售用户数据，不把数据用于个性化广告。

## 保存和删除

本机词本、收藏与设置由 Chrome 扩展存储管理。用户可以在扩展中删除相应记录；清除扩展数据或卸载扩展会删除本机保存的数据。第三方服务商可能按其政策保存用户提交的请求，用户应查阅其政策。

## 使用限制与联系

免译只将数据用于用户主动使用的翻译、字幕、词本和相关学习功能。对于从 Google API 获得的信息，免译遵守 Chrome Web Store 用户数据政策及其“有限使用”要求。有关本扩展的隐私问题，可通过 Chrome 应用商店中本扩展的“支持”页面联系发布者。

# Mianyi Privacy Policy

Effective date: October 4, 2026

Mianyi provides web page, selected-text, and video-caption translation, plus local vocabulary lists. No account is required.

The extension reads the text, selections, captions, and page or video addresses needed for features you use. It processes text selections, translation clicks, and save actions to show results or save chosen content; it does not build a general click or keystroke history. Words, sentences, wordbooks, saved videos, settings, and results that you save are kept in local Chrome extension storage. API keys that you provide are also kept there and are sent directly to the provider you select when a request requires authentication.

When you request a translation, the relevant text and language settings may be sent directly to Google Translate. If you configure another translation or AI provider, the relevant text, captions, prompts, and required API key are sent directly to that provider, such as OpenAI, Google Gemini, DeepL, Anthropic, or DeepSeek. Caption features may also request captions from the video site you are visiting. Those providers handle received data under their own privacy policies.

Mianyi does not operate an account service or translation proxy, send content to the former hosted service, or send usage or installation analytics. We do not sell user data or use it for personalized advertising.

You can remove local records in the extension. Clearing extension data or uninstalling the extension removes locally stored data. A third-party provider may retain submitted requests under its own policy.

Mianyi uses data only for the translation, caption, vocabulary, and related learning features you choose. Use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. For privacy questions, contact the publisher through this extension's Chrome Web Store support page.
